BMI值計算

BMI值計算公式：BMI = 體重(公斤) / 身高²(公尺²)

例如：一個 52 公斤的人，身高是 155 公分，則 BMI 為：

52(公斤) / 1.55² (公尺²) = 21.6

衛生福利部成人 BMI 分級標準：

體重過輕：BMI < 18.5
正常範圍：18.5 ≤ BMI < 24
過重：24 ≤ BMI < 27
輕度肥胖：27 ≤ BMI < 30
中度肥胖：30 ≤ BMI < 35
重度肥胖：BMI ≥ 35
